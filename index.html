Physics-Based Modeling, Simulation and Neural Networks

Lecture notes Essential Concepts in FEM & Physics-Based ML, with worked examples and exercises.

A short introduction to the essentials of finite element modeling and physics-based machine learning, built on intuitive examples small enough to compute by hand. The notes are modular: the core is told in one dimension, and from there separate branches continue to two-dimensional problems, to dynamics and nonlinear problems, to physics-informed and physics-augmented neural networks, and to reduced models of whole solution fields.

Getting started

  1. Install Python 3 and the three libraries the notebooks use (no machine-learning framework is needed): 
    pip install -r requirements.txt
  2. Start Jupyter in this folder and open a notebook from 2_Exercises: 
    jupyter lab
  3. Read the matching chapter first, then work through the notebook part by part, running each check cell.
